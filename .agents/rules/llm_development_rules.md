# Instructions de développement pour les agents IA

La référence complète et maintenue des règles du dépôt se trouve dans
[`AGENTS.md`](../../AGENTS.md). Ce fichier est conservé pour les outils qui
chargent automatiquement `.agents/rules` ; il doit rester synchronisé avec
`AGENTS.md`.

Consulter [`AGENTS.md`](../../AGENTS.md) pour :

- la méthode avant, pendant et après édition ;
- les commandes de tests et de validation Windows ;
- les règles de source unique pour l'UI ;
- les exigences de sécurité, de gestion des ressources et de validation des
  entrées ;
- les conventions MCP et la checklist de clôture.
